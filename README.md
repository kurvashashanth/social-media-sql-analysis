# Social Media SQL Analysis Project

## Project Overview
This project analyzes a social media platform database using SQL to uncover user engagement patterns, influencer rankings, hashtag trends, and activity insights.

## Database Tables
- Users
- Posts
- Comments
- Likes
- Followers
- Hashtags
- Post_Hashtags

## Analysis Performed

### User Analysis
- Most Active Users
- Inactive Users
- Followers Who Never Interacted

### Content Analysis
- Most Liked Posts
- Trending Hashtags
- Hashtags with Highest Engagement

### Influencer Analysis
- Top Influencers
- Most Used Hashtags by Top Influencers

### Engagement Analysis
- User Engagement Rate
- Country-wise Engagement Leaderboard
- Top Countries by Average Engagement

### Activity Analysis
- Busiest Posting Hours

## SQL Concepts Used
- INNER JOIN
- LEFT JOIN
- Subqueries
- Aggregate Functions
- GROUP BY
- HAVING
- COALESCE
- NULLIF
- ORDER BY
- LIMIT

## Project Outcomes
The analysis helps identify:
- Highly active users
- Top-performing content
- Influential creators
- Popular hashtags
- Country-wise engagement trends
